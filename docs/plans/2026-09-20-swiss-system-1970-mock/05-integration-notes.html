Today · static templates
gamedays/wizard/gameday_format.py + SCHEDULE_MAP pick one fixed pairing table by team count, once, before the gameday starts.
The newer gameday_designer models a template as stages[], each with a progressionMode (round_robin, placement) and a progressionMapping of fixed sourceIndex winner/loser refs — resolved once, when the template is authored.
Neither model fits Swiss: pairings can't be known until a round's results exist.
Proposed · swiss resolver
New progressionMode: 'swiss' stage type. Instead of a static progressionMapping, a SwissRoundResolver runs after a round's results are confirmed and generates the next round's games from the seed list + live standings.
Config needs { rounds, fields, gameDuration, seedOrder } — no upfront bracket shape, since nothing about who-plays-whom past Round 1 can be precomputed. Slot count and timing can, though: see below.
New entry in tournamentTemplates.ts / TemplateLibraryModal, same as any built-in template.
Net effect: for this stage type, the designer stops being "author a flow, then run it" and becomes a control loop — enter teams + round count once, then repeatedly generate → play → confirm → generate.
💡 Schema already splits this A game node already separates fieldId / startTime / duration / breakAfter (the reservation) from homeTeamDynamic / awayTeamDynamic (the pairing — null until resolved), the same way a playoff's TBD semifinal slot works today. Fields + duration at setup only need to pre-create every round's slots through the existing auto-time-calc engine ("Phase 1" scheduling); SwissRoundResolver then just fills the two dynamic refs per slot, once that round's results allow it.
Reuses as-is
· GameResultModal for score entry — a Swiss game is scored exactly like any other
· the existing auto-time-calc engine for slot start times
· TeamSelectionModal for the team pool
· LeagueRuleset for point values — win/bye = 2 is a ruleset variant, not bespoke Swiss math

Open questions

· Rematch avoidance and final tie-breaks aren't specified in the AFCV source (only chess-Swiss convention gives Buchholz/Sonneborn-Berger) — needs a ruling before Round 3+
